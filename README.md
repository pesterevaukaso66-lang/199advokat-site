# Сайт адвоката Гарцевой В. А.

Публичный сайт-визитка. Специализация — налоговые преступления (ст. 199, 199.1, 199.2 УК РФ), Москва.

- `index.html` — весь сайт одним файлом (HTML/CSS/JS, фото встроено как base64)
- Хостинг: GitHub Pages
- Домен: 199advokat.ru (после подключения DNS)

Внутренние заметки по стратегии продвижения, факт-лист, ход переговоров — в отдельном
приватном репозитории `Адвокат Гарцева`, сюда не переносятся сознательно.

Правки — через Claude Code или напрямую в `index.html`.
